# Контент курса

Темы и задачи хранятся в JSON и загружаются в базу командой:

```bash
npm run import:content -- content/sample-topics.json            # запись в базу
npm run import:content -- content/sample-topics.json --dry-run  # только проверка файла
```

Повторный импорт обновляет темы (по `order_number`) и задачи (по теме и типу). Темы, которых нет в файле, не удаляются: так прогресс учеников не пропадёт.

## Формат

```json
{
  "topics": [
    {
      "order_number": 1,
      "title": "Название темы",
      "description": "Короткое описание",
      "tasks": [
        {
          "type": "critical",
          "public_text": "Текст задачи для ученика",
          "ai_context": "Коротко: о чём задача, для наставника",
          "grading_criteria": ["Ученик учёл …", "Ученик проверил …"],
          "common_mistakes": ["Типичная ошибка"],
          "hints": ["Подсказка 1", "Подсказка 2", "Подсказка 3"]
        },
        { "type": "engineering", "…": "те же поля" }
      ]
    }
  ]
}
```

Правила (проверяются при импорте):

- `order_number` от 1 до 34, без повторов.
- В каждой теме ровно две задачи: одна `critical` и одна `engineering`.
- Ровно три подсказки.
- `grading_criteria` записываются контрольными точками («ученик учёл …»), а не готовым ответом. Поля для правильного ответа нет и быть не должно.
- `ai_context` короткий: он уходит в каждый запрос к ИИ и тратит токены.
- `ai_context`, `grading_criteria`, `common_mistakes` и подсказки ученик напрямую не видит.
